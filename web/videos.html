GoPro skiing, from YouTube

We collect follow-cam GoPro ski runs as links, not files. Each link is pulled once, read with MediaPipe 3D pose, and turned into G1 joint angles, body lean and a virtual gyroscope, frame by frame.

Sources
gopro_sources.csv50 GoPro ski runs as YouTube links
→
Add a run 
# pull one link
yt-dlp -f mp4 -o "data/videos/gopro/%(id)s.mp4" https://youtu.be/<id>

# pose → G1 joints, written to out/pose/pose_data_<id>.json
python -m skisim.pose_video data/videos/gopro/<id>.mp4 --title "FOLLOW CAM"

The video stays on the machine that ran it. What we keep is the link and the recording: t, kL, kR, lean, gyro, phase, g1 per frame.
